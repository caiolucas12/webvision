Arquitetura do projeto

Este é um protótipo de Frontend criado para a disciplina. Para implementar este projeto no mundo real, a arquitetura recomendada seria:

1. CLIENTE (AGENTE MONITOR)

Um script simples rodando em background em cada computador da rede (feito em Python com a biblioteca psutil, por exemplo). Ele captura uso de CPU/RAM a cada 3 segundos e envia para o servidor via protocolo HTTP (POST) ou WebSocket.

2. SERVIDOR (BACKEND)

Uma API (pode ser feita em Node.js com Express, ou Python com Flask/FastAPI) rodando em uma máquina central. Ela recebe os dados dos agentes e os guarda temporariamente na memória (ou banco de dados tipo Redis/SQLite).

3. DASHBOARD (ESTE FRONTEND)

A interface web apresenta uma visão estática dos equipamentos e dos indicadores de uso. Nesta primeira fase, os dados são exemplos fixos para validar a estrutura e a identidade visual do projeto.
